# Side Notes

A personal, paper-inspired notebook built with Next.js and React. Create, edit,
search, pin, and delete notes. Notes are saved in your browser with local
storage, so they stay available on this device between visits.

## Getting started

Install dependencies and run the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Scripts

- `npm run dev` — start the development server
- `npm run build` — create a production build
- `npm start` — run the production build
- `npm run lint` — check the project with ESLint

Notes are stored locally in the browser and are not synced between devices.
